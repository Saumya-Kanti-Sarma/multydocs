**MultiDocs** is a SaaS tool built for anyone who needs to generate certificates, report cards, or IDs in bulk — without the hassle.

Generating documents one by one is slow and tedious. MultiDocs lets you do it in just a few clicks: pick your template, upload your data, adjust the fields, and download a ready-to-use ZIP file with everything generated.

🌐 **Live site:** [multydocs.developer-saumyasarma.workers.dev](https://multydocs.developer-saumyasarma.workers.dev/)

---

## How It Works

1. **Select a template** — Choose from certificates, report cards, or ID cards.
2. **Upload your data** — Add recipient/student data as a CSV file, or enter it manually.
3. **Map the fields** — Adjust and align the data fields to match your template layout.
4. **Generate & download** — Hit generate and download a ZIP file containing all your documents, ready to go.

---

## Run Locally

You can run MultiDocs locally on your own machine. Just make sure you have [Node.js](https://nodejs.org/) (v18 or higher) and [Git](https://git-scm.com/) installed, then run:

```bash
git clone https://github.com/Saumya-Kanti-Sarma/multydocs.git
cd multydocs/multydocs
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and you're good to go!
